Se propone desarrollar un sistema para gestionar las solicitudes y denuncias de los ciudadanos. 
El sistema almacenará la información de cada ciudadano en una lista y permitirá registrar su solicitud o denuncia, donde las denuncias tienen una medida de prioridad dependiendo la circunstancia, sea una queja, un robo, etc.
Así se contará con una lista de prioridades, en la que los casos serán organizados según su nivel de importancia, tomando como referencia el cuadro de gestión del tiempo, para facilitar una atención ordenada y eficiente.
